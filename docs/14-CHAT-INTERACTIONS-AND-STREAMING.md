# 消息交互、分支重新生成与流式回复

日期：2026-10-23。schema v12，兼容已有数据库的增量迁移。

## 使用入口

| 功能 | 入口与行为 |
| --- | --- |
| 引用 | 消息下方“引用”；引用不在当前分页时可跳转加载 |
| 编辑 | 消息下方“编辑”；支持自己的消息和角色消息，显示已编辑状态 |
| 历史恢复 | 编辑面板展开历史版本，选择原文再保存；保留最近 30 次修改 |
| 重新生成 | 角色回复下方“重新生成”，创建单独会话分支并跳转；原会话和后续消息保留 |
| 撤回 | 自己的消息下方“撤回”；保留撤回事件供角色接戏，清除原文、编辑历史及媒体引用 |
| 删除 | 原有删除入口保留；删除同时清除该消息的编辑历史 |
| 表情 | 消息下方六种常用表情，重复点击取消；新增反应可唤醒角色 |
| 全局搜索 | 消息列表顶部搜索按钮；可筛选会话和发言人 |
| 会话内搜索 | 聊天右上角“更多 → 搜索本会话”，点击结果定位 |

编辑、撤回、删除先阻止当前会话继续工作，取消请求和等待任务，等待运行结束，再修改数据库。内容修订会使摘要和关联自动来源记忆失效。编辑不自动重跑后续对话；可以对后面的角色回复使用重新生成。历史中的已完成工具副作用不会随编辑倒退。

撤回提示包含事件，不会再次向模型提供原文，也不会声称模型必然记得被撤回内容。已生成的其他消息、先前导出的备份及历史音频资产不会被追溯擦除。

## 分支范围

重新生成只复制所选回复之前的消息、引用、提及和反应，复制成员可见范围、世界书绑定及用户会话备注。仅为所选角色派发一次人工重试，分支默认暂停纯角色自主续聊；人类输入仍可正常获得回复。原会话不被清空或修改。

角色资料、人工全局备忘、世界书使用当前配置；这不是整套角色世界状态的时间旅行快照。原会话摘要和会话自动记忆不复制，分支不读取角色的自动全局记忆，避免后续事实透入。新分支产生的会话记忆仍正常工作。开场白之前没有聊天时，提示先发消息。

## SSE 与完成边界

Chat Completions 与 Responses 均支持 SSE。浏览器使用 ReadableStream；Android 由原生 HTTPS 请求持有 Key，通过按 requestId 隔离的桥接事件发送分块，原生取消仍可中断连接。

主回复显示普通文本或 message_send 正文的生成预览。预览不落库；只有结束标记、完整响应及工具参数校验通过，运行时才执行工具并保存消息。取消、截断、失败不会把预览当作正式回复。辅助判断和摘要仍使用普通响应。

明确的“不支持 stream”400/422 响应会回退普通请求，并按连接配置、地址和模型缓存能力；请求 stream 却返回普通 JSON 的线路也缓存回退状态。配置版本改变或重启后会重新探测。网络中断、鉴权失败、普通业务错误不会被当作不支持流式而盲目重发。主运行时的回退请求计入预算和账本。

## 搜索和数据兼容

每页 50 条，按时间与 ID 稳定排序。界面使用最后一条结果作为游标，避免聊天中新插入消息导致翻页重复。搜索排除已删和已撤回原文，支持关键词、会话、作者筛选、高亮与定位。取消和修改查询会使旧查询结果失效；这不等于中断 SQLite 已经执行的语句。

消息新增 recalled、edited_at、edit_history，分支会话新增 branch_sequence。完整加密备份及聊天模块 ZIP 自动携带这些字段；旧备份缺少字段时使用默认值。

## 验证

- `npm run test:messaging`：真实 SQLite、模拟模型网络；覆盖编辑历史与来源失效、分支运行与未来信息隔离、撤回归属与事件、搜索超过 100 条/游标翻页、备份恢复、拆分 SSE/工具预览/usage/失败、能力回退、编辑取消运行中请求、旧表增量迁移。
- 原有 `npm run test:agent` 39 项、`npm run test:local` 和 `node scripts/check-roleplay.cjs` 回归。
- `scripts/check-messaging-ui.cjs`：真实 React 界面和模拟 AppApi，Playwright Chrome 无头模式，390×844 交互检查。覆盖编辑保存、表情、撤回、会话搜索定位和分支跳转；不冒充真实 SQLite 浏览器宿主验收。Playwright 不加入产品依赖，未安装时可用 YOMI_PLAYWRIGHT 指向现有模块。
- TypeScript/Vite production build 与 Android debug 编译。

本轮没有连接 Android 设备，也没有使用真实服务商凭证。Android 原生 SSE 的设备交互、真实服务商流式行为与长时间运行仍待实测。
