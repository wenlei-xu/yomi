## 1. 四个底部入口

| 入口 | 实现内容 |
| --- | --- |
| 消息 | 用户参与的 `direct`/`group` 列表：置顶条、全部/群聊/置顶筛选、隐藏开关、全局搜索、运行时提示条、恢复卡片 |
| 私聊 | `agent_direct`/`agent_group` 列表与只读旁观，顶部常驻说明 |
| 角色 | 角色卡（可用/停用/归档统计）、新建、建群、导入角色、归档开关、记忆面板 |
| 我 | 本地资料、模型连接、摘要继承、用量、备份恢复、清空、关于 |

没有第五个入口；原版的“资料库”按用户要求本版不做。底部导航在选中会话时隐藏，返回后恢复。

## 2. 首次启动

启动即显示“正在打开本地数据…”，然后进“消息”空态：“还没有聊天。先创建角色，再打开单聊或建群。”没有引导流程、没有登录、没有演示角色、没有内置默认端点。本地用户固定为 `我`，可在“我”里改昵称和自我介绍。

数据库打开失败时整页显示“启动失败：原因”，提供不了恢复入口（已知限制）。

## 3. 消息列表

- 顶部：logo + “Yomi” 标题 + 搜索开关。
- 搜索框展开后可搜全部聊天记录，结果行显示“会话标题 · 作者”和正文，点击跳转到该消息并居中高亮。
- 筛选胶囊：全部 / 群聊 / 置顶 / 更多（含隐藏）。
- 置顶会话在列表上方以头像条展示，带未读角标。
- 恢复卡片：每个有最新 `failed`/`interrupted` run 的会话显示“上次回应被中断”+ 原因，操作是打开/重试/略过。
- 运行中：列表顶部出现“N 个角色正在回应 · 全部停止”胶囊。
- 行内显示标题、静音标记、最后一条消息、未读角标、已停止/已隐藏标记、相对时间。

## 4. 聊天页

顶部：返回、标题 + 副标题（群聊显示成员数与“正在回应/已停止/在线”，单聊显示“角色在线/已停止”，旁观显示“角色私聊 · 只读旁观”）、生成中的停止按钮、更多菜单。

横幅：只读旁观说明、暂停说明（“互动已停止；历史仍保留，点击‘继续’才会重新判断。”）、生成中（“X、Y 正在思考”+ 停止）、有新回复时的刷新条。

消息：头像、作者名、时间、气泡、引用块（点击滚动到原消息）、Markdown 渲染、反应计数。自己的消息右侧对齐（`mine`）。已删消息显示“消息已删除”。每条消息下有引用 / ♡ / 删除三个文字按钮。

输入：群聊有 @ 按钮和 `@` 触发选人（chips 可删），单聊只有文本框；Ctrl/Cmd+Enter 发送；草稿 300ms 防抖落库，切会话与重启后恢复；引用预览条可取消。

分页：默认取最新 50 条；“加载更早消息”向前翻页；“有新消息 · 跳到最新”重取合并。搜索跳转用 `messagesAround` 半径 20。没有虚拟列表，没有“有新消息”自动跟随之外的滚动锚点保持逻辑。

更多菜单：导出 Markdown、导出 JSON、清空聊天、删除会话（旁观会话不允许删除，只能清空）。

会话资料面板：群聊可改名称、话题、勾选成员；置顶/静音/暂停角色自主互动/从列表隐藏四个开关；保存时一并提交成员增删。

停止确认弹窗：“停止本轮互动？当前生成和本轮剩余发言会同时取消。已完成的回复会保留，重启后可手动重试。”

## 5. 运行控制与恢复

| 状态 | 界面 |
| --- | --- |
| 生成中 | 顶部停止按钮 + typing 横幅 + 列表胶囊 |
| 已停止 | 顶部“继续”按钮 + “互动已停止”横幅 |
| 上次中断 | 消息列表恢复卡片（打开/重试/略过） |
| 预算耗尽 | 继续后可开新周期；界面不单独展示预算状态 |
| 缺连接/缺 Key | 发送后 toast：“请先在‘我’中配置可用于角色聊天的主模型。”或“模型凭证缺失，请重新填写 API Key。” |
| 模型未按协议发言 | toast：“模型没有按要求完成本轮发言，请重试。” |

## 6. 私聊旁观

列表为空时显示“角色之间还没有自动开启私聊。”顶部长条说明：“这里显示角色之间的对话。你是设备所有者，可以旁观和管理，但不能以任何角色身份插入发言。”

旁观聊天页没有输入框，其余（分页、引用、导出、清空、停止）与普通聊天一致。`agent_*` 会话不能在“消息”里删除。

## 7. 角色与记忆

角色卡：头像（`Avatar` 按 ID 哈希取色，无图时用渐变字母图）、名称、说话风格、状态标签、简介引用、`chat / memory / whisper` 三个标签、编辑资料与记忆按钮。点卡体进入单聊（`openDirect` 复用同一会话）。

操作行：新角色、建群、导入（`.json` / `.yomi-character.json`）、归档显隐。

编辑器：名称、简介、人设、说话风格、头像颜色、选择头像图片（≤ 2 MB，前端缩放到 256px JPEG）、启用/允许主动私聊/允许建立角色小组开关；已有角色可归档、复制、导出、删除。

复制角色生成新 ID，只复制资料（`copyAgent` 不复制记忆与会话）。删除角色确认文案：“彻底删除角色、记忆及角色间私聊关联？历史消息仍保留作者名称。”

记忆面板：新增记忆（可选全局或指定会话）、列表显示“会话记忆/全局记忆 · 你创建/角色记录 · 日期”、置顶、编辑、设为全局/限定会话、删除。提示文案说明文字记忆按角色隔离。

## 8. “我”

- 本地资料：昵称、自我介绍、保存。
- 模型连接：连接列表（协议 + Key 状态）、添加/编辑/删除、测试连接、摘要模型继承主模型。
- 连接表单：名称、协议（Responses / Chat Completions）、Base URL、模型 ID、上下文、输出上限；保存时原生弹窗录入 Key；提示“Key 由 Android Keystore 加密；数据库和备份不保存明文。主模型需要支持工具调用。”
- 用量：调用次数、token 合计或“部分用量未知”、展开最近 30 条（时间、purpose、状态、模型、token）。
- 数据与备份：导出备份、恢复备份（文件选择 + 确认）、清空全部数据（输入“清空”确认）。
- 关于：本地优先说明、文字记忆与关键词检索说明、无 embedding、无资料库与工作型工具、“Android v1 · 数据不会自动上传或云同步”。

## 9. 与原设计的差异

- 没有深/浅主题、文字大小、外观设置；样式写死在 `styles.css`。
- 没有长按菜单，消息操作是常驻文字按钮；表情只有 ♡。
- 没有无障碍标签体系（图标按钮有 `aria-label`，但无 TalkBack 专门验证）、没有 reduced-motion 处理。
- 没有活动概览页、互动偏好页、连接详情页、外观页、诊断导出。
- 搜索没有分页/取消/过滤，`LIMIT 100` 一次返回。
- 导出文件直接写 `Documents`，没有分享面板与保存位置选择。

## 10. 移动行为

- `capacitor.config.ts`：`androidScheme: 'https'`、`allowMixedContent: false`。
- `AndroidManifest.xml` 只申请 `INTERNET`；`MainActivity` 注册 `SecureVaultPlugin`，`launchMode=singleTask`，`configChanges` 覆盖键盘/尺寸/方向。
- 安全区用 `env(safe-area-inset-bottom)`；输入区固定在底部。
- Android 返回：聊天页用 history `pushState`/`popstate` 实现返回列表；底部导航在会话页隐藏。
- 后台：退到后台即停止所有运行中的会话。
- 没有虚拟列表、没有键盘自适应滚动、没有外接键盘专门处理（Ctrl/Cmd+Enter 已支持）。
